💡 ListView Features Demonstrated

This page showcases several important ListView capabilities:

🔍 Search Functionality

Custom get_queryset() method implements search across multiple fields using Django Q objects.

Q(title__icontains=search) | Q(description__icontains=search)

🏷️ Category Filtering

Filter books by category using URL parameters processed in the queryset method.

queryset.filter(category__slug=category)

📄 Pagination

Built-in pagination with paginate_by = 10 attribute.

{{ page_obj.number }} of {{ page_obj.paginator.num_pages }}

🚀 Query Optimization

Using select_related() and prefetch_related() to minimize database queries.

select_related('category').prefetch_related('authors')

📊 Context Data

Custom context variables added via get_context_data() method.

context['total_count'] = self.get_queryset().count()
