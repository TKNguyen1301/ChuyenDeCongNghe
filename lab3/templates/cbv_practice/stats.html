🔍 Data Analysis Examples

This statistics page demonstrates several Django ORM features:

📊 Count Aggregations

Simple counting using .count() method:

Book.objects.count()

Result: {{ total_books }} total books

🔢 Annotations

Adding calculated fields with .annotate():

Category.objects.annotate(book_count=Count('books'))

Enables sorting categories by popularity

📅 Date Filtering

Time-based filtering with timedelta:

Book.objects.filter(created_at__gte=thirty_days_ago)

Recent books: {{ recent_books }}

🔗 Complex Filters

Using Q objects and filter conditions:

Author.objects.annotate(recent_books=Count('books', filter=Q(...)))

📋 Ordering

Sorting by annotated fields:

.order_by('-book_count')

💻 TemplateView Implementation

This page demonstrates how to create rich dashboard views using TemplateView:

class StatsView(TemplateView):
    template_name = 'cbv_practice/stats.html'
    
    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        
        # Time calculations
        now = timezone.now()
        thirty_days_ago = now - timedelta(days=30)
        
        # Basic counts
        context.update({
            'total_books': Book.objects.count(),
            'available_books': Book.objects.filter(is_available=True).count(),
            'total_authors': Author.objects.count(),
            # ... more context data
        })
        
        return context

🚀 Performance Insights

🎯 Query Optimization

All statistics are calculated in a single view method, minimizing database hits.

📊 Annotation Benefits

Using database-level counting instead of Python loops for better performance.

🔄 Caching Potential

This data could be cached to improve response times for frequently accessed statistics.

📈 Scalability

ORM aggregations scale well with large datasets compared to Python calculations.
