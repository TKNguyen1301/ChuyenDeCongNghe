Custom Template Tags & Filters

Django allows you to create custom template tags and filters to extend the template language with your own functionality.

Custom Filters

Filters transform variables and can take arguments.

Assignment Tags

Assignment tags perform computation and set the result to a context variable.

{% templatetag openblock %} get_random_posts 3 as random_posts {% templatetag closeblock %}
{% templatetag openblock %} for post in random_posts {% templatetag closeblock %}
  - {{ post.title }}
{% templatetag openblock %} endfor {% templatetag closeblock %}

{% templatetag openblock %} generate_uuid as unique_id {% templatetag closeblock %}
ID: {{ unique_id }}
{% get_random_posts 3 as random_posts %} {% for post in random_posts %} - {{ post.title }}
{% endfor %}
{% generate_uuid as unique_id %} ID: {{ unique_id }}

How to Create Custom Tags & Filters

1. Create Template Tag Library

# templatetags/blog_extras.py
from django import template
from django.utils.safestring import mark_safe
import re
import random

register = template.Library()

# Simple Filter
@register.filter
def multiply(value, arg):
    """Multiply value by argument"""
    try:
        return int(value) * int(arg)
    except (ValueError, TypeError):
        return 0

# Filter with multiple arguments
@register.filter
def abbreviate(value, max_length):
    """Abbreviate text to max_length characters"""
    if len(value) <= max_length:
        return value
    return value[:max_length-3] + "..."

# Simple Tag
@register.simple_tag
def current_time(format_string):
    """Return current time in specified format"""
    from datetime import datetime
    return datetime.now().strftime(format_string)

# Assignment Tag
@register.simple_tag
def get_random_posts(count):
    """Get random posts"""
    from .models import Post
    posts = list(Post.objects.all())
    return random.sample(posts, min(count, len(posts)))

# Inclusion Tag
@register.inclusion_tag('templatetags/recent_posts.html')
def recent_posts(count=5):
    """Render recent posts widget"""
    from .models import Post
    posts = Post.objects.order_by('-created_at')[:count]
    return {'posts': posts}

3. Advanced Tag with Parser

@register.tag
def format_list(parser, token):
    """Format list with custom template"""
    try:
        tag_name, var_name, template_name = token.split_contents()
    except ValueError:
        raise template.TemplateSyntaxError(
            f"{token.contents.split()[0]} tag requires exactly two arguments"
        )
    return FormatListNode(var_name, template_name)

class FormatListNode(template.Node):
    def __init__(self, var_name, template_name):
        self.var_name = template.Variable(var_name)
        self.template_name = template.Variable(template_name)
    
    def render(self, context):
        try:
            items = self.var_name.resolve(context)
            template_name = self.template_name.resolve(context)
            # Custom rendering logic
            return render_to_string(template_name, {'items': items})
        except template.VariableDoesNotExist:
            return ''

Best Practices

Tips
  • Handle exceptions gracefully
  • Use mark_safe() for HTML output
  • Keep filters simple and focused
  • Use inclusion tags for reusable widgets
  • Document your custom tags
  • Test edge cases thoroughly
Gotchas
  • Filters can't access request context
  • Be careful with HTML escaping
  • Template tag library names must be unique
  • Complex logic belongs in views, not templates
  • Performance: database queries in tags
  • Import templatetags properly

Performance Considerations

Database Queries

Be careful with database queries in custom tags:

# ❌ Bad: N+1 queries
@register.inclusion_tag('tags/post_list.html')
def recent_posts_bad():
    posts = Post.objects.all()[:5]
    return {'posts': posts}  # Each post.author access = 1 query

# ✅ Good: Optimized queries
@register.inclusion_tag('tags/post_list.html')
def recent_posts_good():
    posts = Post.objects.select_related('author').prefetch_related('tags')[:5]
    return {'posts': posts}  # Optimized with joins
Caching

Cache expensive operations:

from django.core.cache import cache

@register.simple_tag
def expensive_calculation():
    result = cache.get('expensive_result')
    if result is None:
        # Expensive operation
        result = perform_calculation()
        cache.set('expensive_result', result, 300)  # 5 minutes
    return result
