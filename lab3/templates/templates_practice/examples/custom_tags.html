Custom Template Tags & Filters

Django allows you to create custom template tags and filters to extend the template language with your own functionality.

Custom Filters

Filters transform variables and can take arguments.

String Manipulation Filters

Template Code:
{% templatetag openblock %} load blog_extras {% templatetag closeblock %}
{{ "hello world"|smart_title }}
{{ "This is a test"|abbreviate:10 }}
{{ "john.doe@example.com"|mask_email }}
{{ "Hello World"|to_camel_case }}
{{ "CamelCase"|to_snake_case }}
Output:
{{ "hello world"|smart_title }}
{{ "This is a test"|abbreviate:10 }}
{{ "john.doe@example.com"|mask_email }}
{{ "Hello World"|to_camel_case }}
{{ "CamelCase"|to_snake_case }}

Number & Math Filters

{{ 123456|format_number }}
{{ 42|multiply:3 }}
{{ 100|percentage:200 }}
{{ 15.75|round_currency }}

{{ 42|multiply:3 }}

UI & Utility Filters

Custom Template Tags

Simple Tags

Simple tags are functions that take arguments and return a string.

{% templatetag openblock %} current_time "Y-m-d H:i:s" {% templatetag closeblock %}
{% templatetag openblock %} random_quote {% templatetag closeblock %}
{% templatetag openblock %} user_greeting "John" {% templatetag closeblock %}
{% templatetag openblock %} calculate_total 10 20 30 {% templatetag closeblock %}
{% current_time "Y-m-d H:i:s" %}
{% random_quote %}
{% user_greeting "John" %}
{% calculate_total 10 20 30 %}

Assignment Tags

Assignment tags perform computation and set the result to a context variable.

{% templatetag openblock %} get_random_posts 3 as random_posts {% templatetag closeblock %}
{% templatetag openblock %} for post in random_posts {% templatetag closeblock %}
  - {{ post.title }}
{% templatetag openblock %} endfor {% templatetag closeblock %}

{% templatetag openblock %} generate_uuid as unique_id {% templatetag closeblock %}
ID: {{ unique_id }}
{% get_random_posts 3 as random_posts %} {% for post in random_posts %} - {{ post.title }}
{% endfor %}
{% generate_uuid as unique_id %} ID: {{ unique_id }}

Inclusion Tags

Inclusion tags render a template with context and return the result.
