Django Template Filters Examples

Template filters transform the values of variables and tag arguments. They provide a way to format, manipulate, and process data before displaying it.

Built-in Filters

Django provides many built-in filters for common formatting tasks.

String Filters

Template Code:
{{ "{{ demo_text|upper }}" }}
{{ "{{ demo_text|lower }}" }}
{{ "{{ demo_text|title }}" }}
{{ "{{ demo_text|capfirst }}" }}
{{ "{{ demo_text|length }}" }}
{{ "{{ demo_text|truncatewords:3 }}" }}
{{ "{{ demo_text|truncatechars:20 }}" }}
Output:
{{ demo_text|upper }}
{{ demo_text|lower }}
{{ demo_text|title }}
{{ demo_text|capfirst }}
{{ demo_text|length }}
{{ demo_text|truncatewords:3 }}
{{ demo_text|truncatechars:20 }}

Number Filters

{{ "{{ demo_number|floatformat:2 }}" }}
{{ "{{ demo_number|add:100 }}" }}

{{ "{{ demo_percentage|percentage:1 }}" }}
{{ demo_number|floatformat:2 }}

{{ demo_number|filesizeformat }}
{{ demo_percentage|floatformat:2 }}

Custom Filters

We've created custom filters to extend Django's template functionality.

Text Processing Filters

{{ "{{ demo_text|word_count }}" }}
{{ "{{ demo_long_text|smart_truncate:50 }}" }}
{{ "{{ demo_text|title_case }}" }}
{{ demo_text|cut:" " }}
{{ demo_text|word_count }} words
{{ demo_long_text|smart_truncate:50 }}
{{ demo_text|title_case }}

Chaining Filters

Filters can be chained together to apply multiple transformations.

{{ "{{ demo_text|lower|title }}" }}
{{ "{{ demo_text|truncatewords:2|upper }}" }}
{{ "{{ demo_date|date:'Y-m-d'|default:'No date' }}" }}
{{ "{{ demo_list|slice:':3'|join:', '|title }}" }}
{{ demo_text|lower|title }}
{{ demo_text|truncatewords:2|upper }}
{{ demo_date|date:"Y-m-d"|default:"No date" }}
{{ demo_list|slice:":3"|join:", "|title }}

Filter Arguments

Many filters accept arguments to customize their behavior.

Filter Template Code Output Description
truncatewords {{ "{{ demo_text|truncatewords:3 }}" }} {{ demo_text|truncatewords:3 }} Truncate after 3 words
slice {{ "{{ demo_list|slice:':3' }}" }} {{ demo_list|slice:":3"|join:", " }} Get first 3 items
date {{ "{{ demo_date|date:'F j, Y' }}" }} {{ demo_date|date:"F j, Y" }} Format date
floatformat {{ "{{ demo_number|floatformat:2 }}" }} {{ demo_number|floatformat:2 }} Round to 2 decimal places
