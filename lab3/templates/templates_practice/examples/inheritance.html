Django Template Inheritance

Template inheritance allows you to build a base "skeleton" template that contains all the common elements of your site and defines blocks that child templates can override.

Template Inheritance Hierarchy

base.html

Base template with common structure

title header content sidebar footer
home.html

Overrides: content

post_list.html

Overrides: title, content

post_detail.html

Overrides: title, content, sidebar

Block Tag Usage

Basic Block Definition

In a base template, blocks define sections that can be overridden:

<!-- base.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{% templatetag openblock %} block title {% templatetag closeblock %}My Site{% templatetag openblock %} endblock {% templatetag closeblock %}</title>
</head>
<body>
    <header>
        {% templatetag openblock %} block header {% templatetag closeblock %}
            <h1>Welcome to My Site</h1>
        {% templatetag openblock %} endblock {% templatetag closeblock %}
    </header>
    
    <main>
        {% templatetag openblock %} block content {% templatetag closeblock %}
            <p>Default content</p>
        {% templatetag openblock %} endblock {% templatetag closeblock %}
    </main>
    
    <footer>
        {% templatetag openblock %} block footer {% templatetag closeblock %}
            <p>© 2024 My Site</p>
        {% templatetag openblock %} endblock {% templatetag closeblock %}
    </footer>
</body>
</html>

Block Override in Child Template

<!-- child.html -->
{% templatetag openblock %} extends "base.html" {% templatetag closeblock %}

{% templatetag openblock %} block title {% templatetag closeblock %}Custom Page - {{ block.super }}{% templatetag openblock %} endblock {% templatetag closeblock %}

{% templatetag openblock %} block content {% templatetag closeblock %}
    <h2>Custom Content</h2>
    <p>This content replaces the default content.</p>
{% templatetag openblock %} endblock {% templatetag closeblock %}

Using {{ block.super }}

The {{ block.super }} variable includes content from the parent block:

Template Code:
{% templatetag openblock %} block content {% templatetag closeblock %}
    {{ block.super }}
    <p>Additional content</p>
{% templatetag openblock %} endblock {% templatetag closeblock %}
Result:
Default content from parent
Additional content

Multi-level Inheritance

Level 1: base.html
<html>
<head>
    <title>{% templatetag openblock %} block title {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}</title>
</head>
<body>
    {% templatetag openblock %} block content {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}
</body>
</html>
Level 2: section_base.html
{% templatetag openblock %} extends "base.html" {% templatetag closeblock %}

{% templatetag openblock %} block content {% templatetag closeblock %}
    <nav>Section Nav</nav>
    {% templatetag openblock %} block section_content {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}
{% templatetag openblock %} endblock {% templatetag closeblock %}
Level 3: page.html
{% templatetag openblock %} extends "section_base.html" {% templatetag closeblock %}

{% templatetag openblock %} block title {% templatetag closeblock %}Page Title{% templatetag openblock %} endblock {% templatetag closeblock %}

{% templatetag openblock %} block section_content {% templatetag closeblock %}
    <h1>Page Content</h1>
{% templatetag openblock %} endblock {% templatetag closeblock %}

Common Inheritance Patterns

1. Layout Templates

<!-- layouts/two_column.html -->
{% templatetag openblock %} extends "base.html" {% templatetag closeblock %}

{% templatetag openblock %} block content {% templatetag closeblock %}
<div class="row">
    <div class="col-md-8">
        {% templatetag openblock %} block main_content {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}
    </div>
    <div class="col-md-4">
        {% templatetag openblock %} block sidebar {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}
    </div>
</div>
{% templatetag openblock %} endblock {% templatetag closeblock %}
<!-- page.html -->
{% templatetag openblock %} extends "layouts/two_column.html" {% templatetag closeblock %}

{% templatetag openblock %} block main_content {% templatetag closeblock %}
    <h1>Main Content</h1>
{% templatetag openblock %} endblock {% templatetag closeblock %}

{% templatetag openblock %} block sidebar {% templatetag closeblock %}
    <h3>Sidebar</h3>
{% templatetag openblock %} endblock {% templatetag closeblock %}

2. Section Templates

<!-- blog/base.html -->
{% templatetag openblock %} extends "base.html" {% templatetag closeblock %}

{% templatetag openblock %} block extra_css {% templatetag closeblock %}
    <link rel="stylesheet" href="blog.css">
{% templatetag openblock %} endblock {% templatetag closeblock %}

{% templatetag openblock %} block content {% templatetag closeblock %}
    <nav>Blog Navigation</nav>
    {% templatetag openblock %} block blog_content {% templatetag closeblock %}{% templatetag openblock %} endblock {% templatetag closeblock %}
{% templatetag openblock %} endblock {% templatetag closeblock %}
<!-- blog/post_detail.html -->
{% templatetag openblock %} extends "blog/base.html" {% templatetag closeblock %}

{% templatetag openblock %} block blog_content {% templatetag closeblock %}
    <article>
        <h1>{{ post.title }}</h1>
        <p>{{ post.content }}</p>
    </article>
{% templatetag openblock %} endblock {% templatetag closeblock %}

3. Conditional Block Extension

{% templatetag openblock %} block extra_head {% templatetag closeblock %}
    {% templatetag openblock %} if user.is_staff {% templatetag closeblock %}
        <link rel="stylesheet" href="admin-styles.css">
    {% templatetag openblock %} endif {% templatetag closeblock %}
    {{ block.super }}
{% templatetag openblock %} endblock {% templatetag closeblock %}

Best Practices

Do's
  • Use descriptive block names
  • Keep blocks focused and single-purpose
  • Provide default content in base blocks
  • Use {{ block.super }} when extending content
  • Create intermediate templates for common layouts
  • Keep inheritance hierarchies shallow
Don'ts
  • Don't create too many inheritance levels
  • Don't make blocks too granular
  • Don't forget {% templatetag openblock %} extends {% templatetag closeblock %} as first line
  • Don't duplicate content across templates
  • Don't use inheritance for simple includes
  • Don't nest blocks unnecessarily
