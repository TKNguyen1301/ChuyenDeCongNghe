Django Template Tags Examples

Template tags provide arbitrary logic in the rendering process. They can output content, serve as control structures, or access other template functionality.

Control Structure Tags

For Loop Tag

The {% templatetag openblock %} for {% templatetag closeblock %} tag allows you to iterate over sequences.

Template Code:
{% templatetag openblock %} for user in user_list {% templatetag closeblock %}
  {{ forloop.counter }}. {{ user }}
  {% templatetag openblock %} if forloop.first {% templatetag closeblock %}(First){% templatetag openblock %} endif {% templatetag closeblock %}
  {% templatetag openblock %} if forloop.last {% templatetag closeblock %}(Last){% templatetag openblock %} endif {% templatetag closeblock %}
{% templatetag openblock %} endfor {% templatetag closeblock %}
Output:
{% for user in user_list %} {{ forloop.counter }}. {{ user }} {% if forloop.first %}(First){% endif %} {% if forloop.last %}(Last){% endif %}
{% endfor %}

For Empty

{% templatetag openblock %} for item in empty_list {% templatetag closeblock %}
  {{ item }}
{% templatetag openblock %} empty {% templatetag closeblock %}
  No items found.
{% templatetag openblock %} endfor {% templatetag closeblock %}
{% for item in empty_list %} {{ item }} {% empty %} No items found. {% endfor %}

If Statements

{% templatetag openblock %} if conditions.is_morning {% templatetag closeblock %}
  Good morning!
{% templatetag openblock %} elif conditions.is_weekend {% templatetag closeblock %}
  Happy weekend!
{% templatetag openblock %} else {% templatetag closeblock %}
  Hello there!
{% templatetag openblock %} endif {% templatetag closeblock %}
{% if conditions.is_morning %} Good morning! {% elif conditions.is_weekend %} Happy weekend! {% else %} Hello there! {% endif %}

Complex Conditions

  Good morning, {{ user.username }}!
{% templatetag openblock %} endif {% templatetag closeblock %}

Template Organization Tags

Include Tag

The {% templatetag openblock %} include {% templatetag closeblock %} tag loads and renders another template.

{% templatetag openblock %} include "templates_practice/includes/alert.html" with message="Hello from include!" type="success" {% templatetag closeblock %}
Hello from include! (This would be an included template)

Block Tag

The {% templatetag openblock %} block {% templatetag closeblock %} tag defines sections that child templates can override.

{% templatetag openblock %} block content {% templatetag closeblock %}
  Default content here
{% templatetag openblock %} endblock {% templatetag closeblock %}

Extends Tag

{% templatetag openblock %} extends "base.html" {% templatetag closeblock %}

Advanced Tags

With Tag

The {% templatetag openblock %} with {% templatetag closeblock %} tag caches complex variables.

{% templatetag openblock %} with total=posts_sample|length {% templatetag closeblock %}
  Total posts: {{ total }}
  {% templatetag openblock %} if total > 5 {% templatetag closeblock %}
    Many posts!
  {% templatetag openblock %} endif {% templatetag closeblock %}
{% templatetag openblock %} endwith {% templatetag closeblock %}
{% with total=posts_sample|length %} Total posts: {{ total }}
{% if total > 3 %} Many posts!
{% endif %} {% endwith %}

Spaceless Tag

{% templatetag openblock %} spaceless {% templatetag closeblock %}
  <p>
    <strong>Bold</strong> text
  </p>
{% templatetag openblock %} endspaceless {% templatetag closeblock %}
{% spaceless %}

Bold text

{% endspaceless %}

Cycle Tag

{% templatetag openblock %} for item in user_list {% templatetag closeblock %}
  <tr class="{% templatetag openblock %} cycle 'row1' 'row2' {% templatetag closeblock %}">
    <td>{{ item }}</td>
  </tr>
{% templatetag openblock %} endfor {% templatetag closeblock %}
{% for item in user_list %} {% endfor %}
{{ item }}

Nested Loops and Complex Logic

Nested For Loops

{% templatetag openblock %} for row in nested_list {% templatetag closeblock %}
  Row {{ forloop.counter }}:
  {% templatetag openblock %} for item in row {% templatetag closeblock %}
    {{ item }}{% templatetag openblock %} if not forloop.last {% templatetag closeblock %}, {% templatetag openblock %} endif {% templatetag closeblock %}
  {% templatetag openblock %} endfor {% templatetag closeblock %}
{% templatetag openblock %} endfor {% templatetag closeblock %}
{% for row in nested_list %} Row {{ forloop.counter }}: {% for item in row %} {{ item }}{% if not forloop.last %}, {% endif %} {% endfor %}
{% endfor %}
