Django Template Engine Examples

This page demonstrates the Django template language syntax including variables, context lookups, and various data types.

Template Variables

Variables are surrounded by {{ "{{" }} and {{ "}}" }} and output values from the context.

Template Code:
{{ "{{ demo_string }}" }}
{{ "{{ demo_number }}" }}
{{ "{{ demo_boolean }}" }}
{{ "{{ demo_list.0 }}" }}
{{ "{{ demo_dict.name }}" }}
Output:
{{ demo_string }}
{{ demo_number }}
{{ demo_boolean }}
{{ demo_list.0 }}
{{ demo_dict.name }}

Context Data Types

String Variables

demo_string = "{{ demo_string }}"
Length: {{ "{{ demo_string|length }}" }}
demo_string = "{{ demo_string }}"
Length: {{ demo_string|length }}

Number Variables

demo_number = {{ "{{ demo_number }}" }}
Plus 10: {{ "{{ demo_number|add:10 }}" }}
Formatted: {{ "{{ demo_number|floatformat:2 }}" }}
demo_number = {{ demo_number }}
Plus 10: {{ demo_number|add:10 }}
Formatted: {{ demo_number|floatformat:2 }}

List Variables

demo_list = {{ "{{ demo_list }}" }}
First item: {{ "{{ demo_list.0 }}" }}
Last item: {{ "{{ demo_list|last }}" }}
Length: {{ "{{ demo_list|length }}" }}
demo_list = {{ demo_list }}
First item: {{ demo_list.0 }}
Last item: {{ demo_list|last }}
Length: {{ demo_list|length }}

Dictionary Variables

demo_dict.name = {{ "{{ demo_dict.name }}" }}
demo_dict.version = {{ "{{ demo_dict.version }}" }}
demo_dict.language = {{ "{{ demo_dict.language }}" }}
demo_dict.framework_type = {{ "{{ demo_dict.framework_type }}" }}
demo_dict.name = {{ demo_dict.name }}
demo_dict.version = {{ demo_dict.version }}
demo_dict.language = {{ demo_dict.language }}
demo_dict.framework_type = {{ demo_dict.framework_type }}

Object Access

Django templates use dot notation to access object attributes and dictionary keys.

{{ "{{ demo_object.title }}" }}
{{ "{{ demo_object.description }}" }}
{{ "{{ demo_object.created_at|date:'F j, Y' }}" }}
{{ "{{ demo_object.nested.value }}" }}
{{ "{{ demo_object.nested.count }}" }}
{{ demo_object.title }}
{{ demo_object.description|truncate_chars:50 }}
{{ demo_object.created_at|date:"F j, Y" }}
{{ demo_object.nested.value }}
{{ demo_object.nested.count }}

HTML Content and Safety

Django automatically escapes HTML content for security. Use the safe filter or autoescape tag to control this behavior.

HTML Escaping (Default)

{{ "{{ html_content }}" }}
{{ html_content }}

Safe HTML Output

{{ "{{ html_content|safe }}" }}
{{ html_content|safe }}

Context Processors

Context processors automatically add variables to all template contexts.

SITE_NAME = {{ "{{ SITE_NAME }}" }}
CURRENT_YEAR = {{ "{{ CURRENT_YEAR }}" }}
DEBUG = {{ "{{ DEBUG }}" }}
is_authenticated = {{ "{{ is_authenticated }}" }}
user_full_name = {{ "{{ user_full_name|default:'Anonymous' }}" }}
SITE_NAME = {{ SITE_NAME }}
CURRENT_YEAR = {{ CURRENT_YEAR }}
DEBUG = {{ DEBUG }}
is_authenticated = {{ is_authenticated }}
user_full_name = {{ user_full_name|default:"Anonymous" }}

Default Values

Use the default filter to provide fallback values for empty variables.

{{ "{{ empty_variable|default:'Default Value' }}" }}
{{ "{{ none_variable|default:'Nothing here' }}" }}
{{ "{{ demo_string|default:'Fallback' }}" }}
{{ empty_variable|default:"Default Value" }}
{{ none_variable|default:"Nothing here" }}
{{ demo_string|default:"Fallback" }}

Template Comments

Comments in Django templates are ignored during rendering.

{# This is a single-line comment #}

{% comment %}
This is a multi-line comment
that can span several lines
and explain complex template logic
{% endcomment %}
